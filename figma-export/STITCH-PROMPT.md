# Stitch 반입용 프롬프트

Google Stitch 는 코드 임포트가 없습니다. 입력은 **텍스트 프롬프트 + 이미지**뿐이라,
`_png/` 의 스크린샷을 올리면서 아래 텍스트를 같이 넣어 화면을 재생성시킵니다.

- §1 은 프로젝트를 새로 만들 때 **한 번** 넣습니다.
- §2 는 화면마다 PNG 와 함께 넣습니다.

> 값은 `docs/DESIGN-TOKENS.md` 기준입니다. 토큰 값을 바꾸면 여기도 같이 고쳐주세요.

---

## §1 프로젝트 초기 프롬프트 (한 번)

아래 블록을 통째로 복사해 첫 프롬프트로 넣습니다.

```
"숨은여행" — 한국의 덜 알려진 지역을 발굴해 나만의 여행 코스를 만드는 웹 서비스.
데스크톱 웹 우선(콘텐츠 최대 폭 1360px), 한국어 UI.

[톤]
"덜 알려진 곳을 천천히 걷는" 인상. 따뜻한 아이보리 배경에 테라코타 강조색.
차분하고 여백이 넓으며, 채도가 낮다. 관광 앱 특유의 화려함·과한 그림자를 피한다.

[색]
배경         #FAF8F4  (따뜻한 아이보리)
카드/패널     #FFFFFF
입력창/비활성  #F4F1EB
테두리        #E7E1D7
본문 글자     #2E2B26  (따뜻한 기운의 거의 검정)
보조 글자     #8B8377
강조(브랜드)  #D08A5D  (테라코타 — 버튼·링크·선택 상태·지도 동선)
강조 호버     #B9764C
연한 강조 배경 #F6E9DE
세이지        #7A9A7E  ("착한가격업소" 전용 색. 다른 용도로 쓰지 않는다)
세이지 배경   #E9F0E9
오류          #BA1A1A

강조색은 매우 넓게 쓰인다(버튼, 링크, 지도 동선, 선택된 지역, 로고).
채도를 더 올리지 말 것 — 지도에서 눈이 아프다.
배경(#FAF8F4)과 비활성면(#F4F1EB)의 차이는 의도적으로 은은하다.

[타이포]
본문: Pretendard (sans)
제목/로고 워드마크: Gowun Batang (한국어 명조)
  → 제목에 명조를 쓰는 것이 이 서비스의 인상을 만든다. 반드시 유지.
페이지 제목 36px / 섹션 22px / 카드 제목 17px / 본문 15px / 캡션 13px
자간 -0.01em, 행간 1.7

[간격 · 형태]
8px 그리드. 8 / 16 / 24(카드 안쪽) / 32(섹션 사이)
모서리: 카드 12px, 버튼·입력창 8px, 칩·배지·아바타 999px
전환: 250ms ease-out

[컴포넌트]
btn-primary   주 액션. 높이 44px, 강조색 배경, 흰 글자
btn-secondary 보조 액션. 테두리형
chip          태그·경유지 이름. 둥근 배경
badge-sage    착한가격업소 배지 (세이지 색)
card          기본 카드. 흰 배경 + 테두리 + 12px 모서리
header        로고(발자국 마크 + 명조 워드마크) · 검색 · AI 추천 · 내 코스 · 후기 둘러보기 · 프로필
footer        데이터 출처 표기 한 줄

[지도]
한국 시군구 SVG 지도가 서비스의 중심. 육지면 #FAF8F4, 경계선 rgba(139,131,119,.45).
선택된 시군구는 강조색. 지도 색은 UI 테두리와 별개로 관리한다.

[규칙]
- 다크 모드는 없다. 라이트 한 벌만.
- 평점·별점·인기순·혼잡도 UI 는 만들지 않는다 (데이터가 없다).
- 헤더는 로그인/비로그인 두 벌이 필요하다.
- 빈 상태를 항상 같이 설계한다 (후기·내 코스는 빈 상태가 첫인상).
- 비동기로 채워지는 자리는 로딩 상태를 함께 그린다
  (랜드마크 설명, 코스 경로, AI 답변).
```

## §2 화면별 프롬프트

각 화면은 `_png/` 의 해당 PNG 를 올리고 아래 한 줄을 덧붙입니다.
공통 접두어: **"첨부 스크린샷의 화면을 위 디자인 시스템으로 다시 디자인해줘."**

| PNG | 덧붙일 설명 |
|---|---|
| `01-login` | 로그인. 헤더 없음. 이메일·비밀번호 + 소셜 로그인(카카오 #FEE500, 구글 #4285F4) |
| `02-login-error` | 로그인 인증 실패 상태. 오류 메시지와 입력창 오류 테두리 |
| `03-signup` | 회원가입. 헤더 없음 |
| `04-mbti-intro` | 여행 MBTI 검사 시작. 헤더 없음, 전체 화면 |
| `05-mbti-question` | 여행 MBTI 문항. 진행률 표시 + 양자택일 선택지 |
| `06-mbti-result` | 여행 MBTI 결과. 유형 이모지·유형명·한 줄 설명·추천 성향 |
| `07-map-logged-out` | 지도 — 비로그인 헤더(로그인·회원가입 버튼) |
| `08-course-logged-out` | 코스 만들기 — 비로그인. 저장 버튼이 "로그인하고 저장" |
| `09-review-feed` | 후기 둘러보기. 카드 그리드 + MBTI 뱃지. **빈 상태도 함께** |
| `10-map` | 서비스 메인. 좌측 "오늘의 숨은 여행지" 카드 목록 + 시군구 SVG 지도 + 무작위/AI 추천 버튼 |
| `11-map-ai-modal` | 위 화면에서 AI 추천 모달이 열린 상태. 취향·기분 선택 칩 + 자유 입력 |
| `12-region-panel` | 지역 선택 시 열리는 우측 패널. 지역 요약 + 코스 만들기 진입 |
| `13-region-detail` | 지역 상세. 랜드마크 설명은 비동기 → 로딩 상태 필요 |
| `14-course-empty` | 코스 만들기 — 담기 전. 좌측 장소 목록(탭: 관광지/먹거리/착한 식당/특산물), 우측 빈 코스 |
| `15-course-with-stops` | 코스 만들기 — 경유지 담긴 상태. 순서 변경 드래그 핸들 + 동선 지도 |
| `16-my-courses` | 내 코스 목록 |
| `17-course-saved` | 저장 완료. 헤더 없는 트랜잭션 화면. 총 장소·소요시간·이동거리 + 동선 지도 + 다음 행동 3개 |
| `18-review-detail` | 후기 상세. MBTI 뱃지, 공유 |
| `19-review-form` | 후기 작성 |
| `20-profile` | 프로필. MBTI 뱃지 |
| `21-chat` | AI 여행 상담 첫 진입(예시 질문). **대화 말풍선 상태는 새로 디자인 필요 — 캡처 없음** |
| `22-my-courses-empty` | 내 코스 — 빈 상태 |

## 반입 후 확인할 것

1. 제목이 **명조(Gowun Batang)** 로 유지됐는지 — Stitch 가 sans 로 바꿔버리기 쉽습니다.
2. 세이지색이 착한가격업소 외의 곳에 쓰이지 않았는지.
3. 평점·별점 UI 가 생기지 않았는지 (`docs/DATA.md` §8 — 만들 수 없는 데이터).
4. 토큰 **이름**이 유지됐는지. 값은 바뀌어도 되지만 이름 체계가 바뀌면 구현 시 화면 전체를 손봐야 합니다.
