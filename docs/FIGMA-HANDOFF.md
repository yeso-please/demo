## 검증과 제한

- Figma 20개 이미지 채움 확인. 모든 구역의 placeholder 해제 및 텍스트·카드 경계 넘침 없음 확인.
- 주요 구역 6개와 상세 계획 카드 렌더링을 시각적으로 확인했다.
- 대포 smoke: PASS, 250개 지역. 마우스/터치 이동, 아바타 탑승, 점화·비행·착지, 오류 복구, 건너뛰기, reduced-motion 확인.
- cannon-game-fx.js / cannon-launcher.js 구문 검사 및 git diff --check 통과.
- 캡처 스크립트: tools/figma-screen-capture.cjs. 외부 폰트·지도 로딩에 네트워크 접근 필요.
- 샘플 성향과 안동 2일 비회원 초안을 로컬 서버에 생성해 캡처했다. 신규 회원가입·실제 숙박예약은 하지 않았다. 최종 캡처 초안 ID: 12, 앞선 실패 실행의 샘플 초안도 남아 있다.
- 전체 계정·저장·확정 API의 회귀 QA를 수행한 것은 아니다.

## 문서화 중 발견한 구현 경계

1. 친구 아바타는 로컬 별명이며 친구 초대·그룹 성향·공동 편집은 준비 중이다.
2. 상세 Day 계획 이동시간은 직선거리 보정 추정치다. 기존 코스 편집기의 카카오 경로 기능과 구분해야 한다.
3. 숙소 링크는 Airbnb 지역명 검색이다. 관광지 좌표 중심 검색·예약 확인·결제는 제공하지 않는다.
4. Day의 장소 추가 링크는 기존 코스 편집기로 이동하지만 해당 Day로 추가되는 연결은 미완료다.
5. 먹거리 후보에 미용실·세탁소 등 비음식 업종이 섞인다. 음식점 업종 필터와 좌표 품질 검증이 필요하다. 이번 Figma 문서화 작업에서는 해당 기능을 수정하지 않았다.
6. PRD의 음식점 자동추천 보류 결정과 현재 후보 선택 UI의 범위를 팀에서 정리해야 한다.
