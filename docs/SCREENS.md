# 1부. 신규 화면

## 1.1 데이터 수집 동의 🆕 `P0`

| | |
|---|---|
| 목적 | 방문 이력·행동 로그 수집 고지 및 동의 (PRD §12 개인정보) |
| 위치 | 회원가입 직후, **방문 이력 온보딩보다 앞** |
| 로그인 필요 | 가입 흐름의 일부 |

**왜 앞에 있어야 하나** — 방문 이력은 위치성 개인정보이고 이후 모든 행동 로그가 학습 입력이 됩니다.
동의 없이 온보딩을 시작하면 수집한 데이터를 쓸 수 없습니다.

| 구성 | |
|---|---|
| 수집 항목 | 방문 지역·만족도·경험 태그, 서비스 내 탐색·저장·길찾기 기록 |
| 이용 목적 | 개인화 추천, 추천 모델 개선 |
| 보관·삭제 | 언제든 `/settings/data`에서 삭제·철회 가능함을 명시 |
| 액션 | `[동의하고 시작하기]` · `[나중에]`(→ 개인화 없이 지도로) |

**상태** — 기본 · 동의 거부(비개인화 모드 안내) · 재동의 요청

## 1.2 방문 이력 온보딩 🆕 `P0` — 가장 큰 신규 작업

| | |
|---|---|
| 경로 | `/onboarding/visits` |
| 목적 | Traveler DNA 의 유일한 Cold Start 입력 (F-02) |
| 로그인 필요 | ❌ (비로그인은 로컬 보관 후 가입 시 이관) |
| 수용 기준 | **3개 이상 입력 시 Traveler DNA 생성 가능** |

**4단계지만 한 화면 안에서 진행합니다.** 페이지를 4번 넘기면 G2(온보딩 완료율)가 먼저 깨집니다.

```
┌──────────────────────────────────────────────┐
│  기억에 남는 국내 여행지를 골라주세요            │
│                                    3 / 7 ✓   │
│  ┌────────────────────────────────────────┐  │
│  │        [전국 시군구 지도 — 탭해서 선택]   │  │
│  └────────────────────────────────────────┘  │
│  선택: (군산 ×) (통영 ×) (경주 ×)             │
│                                              │
│  ─ 칩을 누르면 아래가 펼쳐집니다 ─              │
│  군산은 어땠나요?                              │
│  (다시 가고 싶어요)(좋았어요)(보통)(안 맞았어요)  │
│                                              │
│  뭐가 좋았나요?              [건너뛰기]        │
│  풍경 산책 골목 역사 시장 음식 카페 체험 축제 휴식│
│                                              │
│  기억나는 곳이 있나요?        [기억 안 남]      │
│  (근대문화거리) (선유도) (전통시장) …           │
│                                              │
│            [ 내 여행 DNA 보기 ]                │
└──────────────────────────────────────────────┘
```

| 단계 | 필수 | 버튼 |
|---|---|---|
| 1 지역 선택 | ✅ 3~7개 | 지도 폴리곤 탭 · 칩 삭제(×) |
| 2 만족도 | ✅ 지역마다 | 4택 1 (다시 가고 싶어요 / 좋았어요 / 보통 / 안 맞았어요) |
| 3 경험 태그 | ❌ | 태그 토글 1~3개 · `[건너뛰기]` |
| 4 기억나는 장소 | ❌ | 장소 선택 · `[기억 안 남]` |

**상태**
- 0개 — 안내 문구, CTA 비활성
- 1~2개 — "**{n}곳만 더** 골라주세요", CTA 비활성
- 3개↑ — CTA 활성 (여기서 바로 끝낼 수 있어야 함)
- 7개 — 상한 도달 안내
- 지도 로딩 · 비로그인(로컬 보관 안내)

⚠ **최소 3개에서 즉시 결과를 볼 수 있어야 합니다.** 7개를 채우도록 유도하면 이탈합니다(리스크: 온보딩 마찰).

## 1.3 여행 DNA 결과 🆕 `P0`

| | |
|---|---|
| 경로 | `/onboarding/dna` |
| 목적 | 연속 벡터를 이해 가능한 문장·태그로 번역 (F-03) |
| 수용 기준 | 입력 근거와 일치하는 상위 취향 + 미방문 후보 수 표시 |

```
        당신의 여행은
   "골목을 따라 지역의 시간을 발견하는" 결에 가깝습니다

   골목·도보   ████████░░
   역사        ███████░░░        ← 순위가 아니라 '결'의 표현
   시장·미식   ███████░░░
   자연·풍경   █████░░░░░

   유명 명소 하나보다 장소가 이어지는 동네에서
   만족도가 높았어요.
   ↳ 근거: 군산·통영에서 '골목','시장'을 선택함

   ─────────────────────────────
   이 분석이 나와 맞나요?              ← G2 지표 수집 지점
   [맞아요]  [조금 달라요]  [수정할게요]
   ─────────────────────────────

   비슷한 결인데 아직 안 가본 지역이 12곳 있어요
                        [ 지도에서 보기 ]
```

| 액션 | 동작 |
|---|---|
| `[맞아요]` | 동의 기록 → 지도로 |
| `[조금 달라요]` | 동의 기록(부정) → 지도로. **막지 않는다** |
| `[수정할게요]` | 방문 이력 온보딩으로 복귀 (리스크 대응: 결과 수정 허용) |
| `[지도에서 보기]` | 발견 묶음이 적용된 `/map` |

⚠ **MBTI 처럼 고정 유형으로 분류하지 않습니다.** 내부는 연속 벡터, 화면 표현만 문장입니다(PRD §8.3).
⚠ 막대 그래프는 **지역 간 순위가 아니라 사용자 내부 차원 비교**입니다. 지역명을 함께 줄 세우면 안 됩니다.

**상태** — 분석 중(로딩) · 결과 · 입력 부족(3개 미만 → 온보딩 복귀) · 동의 응답 후

## 1.4 코스 선택 🆕 `P0`

| | |
|---|---|
| 경로 | `/region/courses?sigCd=` (또는 지역 상세 내 섹션) |
| 목적 | 공식 코스와 자동 조립 코스를 **출처를 밝혀** 나란히 제시 (F-06) |
| 수용 기준 | 공식/자동 조립 배지 · 장소 ID 검증 · 코스 저장 가능 |

**공식 코스는 14개 시군구에만 있습니다**(DATA §9). 두 경로의 화면 처리가 반드시 달라야 합니다.

| | 공식 코스 (14곳) | 자동 조립 (250곳 전역) |
|---|---|---|
| 배지 | `공식 코스 · 한국관광공사` | `자동 조립` |
| 부가 표시 | 원본 코스 ID · 갱신일 | 조립 규칙 · 미검증 항목 |
| 표현 | 그대로 제시 | **"코스 구성 가능"** (실행 보장 아님) |
| 이동시간 | `totalDistance` 전량 비어 있음 → **"0km" 노출 금지** | 직선거리 추정(명시) |

| 상태 | 화면 |
|---|---|
| 공식 O + 자동 O | 두 카드 병렬, 공식 우선 배치 |
| 공식 X (236곳) | 자동 조립만. **"이 지역은 공식 코스가 없어 우리가 조립했어요"** |
| 둘 다 X | 후보 목록으로 직접 담기 유도 |

**액션** — `[이 코스로 시작]` · `[다른 조합으로]`(variant+1) · `[직접 만들기]`

## 2.1 지도 `/map` 🔧 — 가장 크게 바뀝니다

**현재** ✅ 250개 폴리곤 · 우측 슬라이드 패널 · 검색 · 무작위 룰렛 · AI 추천 모달 · 오늘의 숨은 여행지 · 이 지역에서 하루 보내기

| v2.0 추가 | 내용 |
|---|---|
| **발견 묶음 필터 칩** | `익숙한 결` `한 걸음 넓히기` `아직 경험 못 한 결` `데이터가 찾은 가능성` |
| **방문/미방문 구분** | 방문 지역은 채도↓ + 체크. **미방문이 기본 강조** |
| **묶음 근거 라벨** | 폴리곤 호버·선택 시 "왜 이 묶음인지" 한 줄 |
| **impression 기록** | 후보 **카드**가 50%·1초 이상 보였을 때만 (F-09 · 아래 확정안) |
| **모바일 바텀시트** | 현재 우측 패널은 데스크톱 전용 (PRD §12 모바일) |
| 지역 검색창 | ⬇ **보조 위치로** — 원칙 1(조건으로 후보를 먼저 닫지 않는다)과 충돌 |
| 오늘의 숨은 여행지 | 발견 묶음의 **재노출 수단**으로 역할 변경 (P1) |
| 무작위 룰렛 | 최소 데이터 품질·코스 생성 가능 지역에서만 (P1) |

**상태 추가** — 온보딩 전(비개인화, 묶음 없음) · 묶음별 빈 상태 · 방문 지역만 남은 경우

> ⚠ **묶음을 색으로만 구분하면 접근성 위반**입니다(PRD §12). 색 + 아이콘 + 칩 라벨 병행.

### impression 판정 — 확정 (2026-08-11)

지도는 250개 폴리곤을 한 번에 그리므로 **"렌더됨"을 노출로 세면 안 됩니다.**
세션마다 250건이 쌓이고, 그중 대부분이 **사용자가 존재조차 모르는 지역**이라 학습 데이터를 망칩니다.

| 등급 | 화면에서 무슨 일이 일어났을 때 | weight |
|---|---|---:|
| **강한 노출** | 발견 묶음 **카드가 뷰포트에 50% 이상 · 1초 이상** 머무름 | 1.0 |
| **약한 노출** | 묶음 선택으로 **폴리곤이 강조**됨 | 0.3 |
| 기록 안 함 | 폴리곤이 그려지기만 함 · 스크롤로 스쳐 지나감 | — |

**화면 설계에 주는 제약**
- 발견 묶음은 **카드 형태**여야 합니다. 폴리곤 색칠만으로는 노출을 판정할 수 없습니다.
- 카드가 한 화면에 너무 많으면(예: 20장 그리드) 스치듯 지나간 것까지 노출로 잡힙니다.
  **묶음당 3~5장**을 유지하고 나머지는 더 보기로 넘깁니다.
- 자동 회전 캐러셀은 쓰지 마세요. 사용자가 안 봤는데 노출이 쌓입니다.
- 같은 세션에서 같은 지역이 반복 노출되면 **1회로 합치고 횟수만 셉니다**(반복 넘김 신호로 별도 활용).

**구현** — `IntersectionObserver { threshold: 0.5 }` + 1초 체류 타이머.
`map.js` 의 '오늘의 숨은 여행지' 무한 스크롤이 이미 같은 패턴을 씁니다(`map.js:335`).

> ⚠ **impression 은 소급 복구가 불가능합니다.** 저장·클릭은 DB 에 남지만
> "보여줬는데 안 고른 것"은 그 순간 기록하지 않으면 영원히 사라집니다.
> 화면을 만들 때 **함께** 심어야 합니다.

# 5부. 설계 시 꼭 지켜야 할 것

1. **빈 상태를 먼저 그리세요.** 발견 묶음(방문 3개만 입력하면 일부 묶음이 빕니다) · 나의 발견 지도 · 내 코스 · 후기.
2. **비동기로 채워지는 자리**를 로딩과 함께 설계하세요 — 여행 DNA 분석, 추천 근거, 랜드마크 설명, 코스 경로, AI 설명.
3. **폴백 화면이 기본값입니다.** LLM 실패·API 한도 소진 시 템플릿 3단 설명으로 대체되며, 이 상태도 정상 화면입니다(PRD §5.4).
4. **온보딩 전/후 두 벌**이 필요합니다 — 지도의 발견 묶음이 있고 없고가 갈립니다. 로그인/비로그인도 여전히 두 벌.
5. **순위를 만들지 마세요.** 내부 점수는 후보 생성과 묶음 구성에만 씁니다. 1위~10위 표기, 별점, 인기순 정렬은 전부 금지.
6. **색만으로 구분하지 마세요.** 발견 묶음·테마·신뢰도 모두 색 + 아이콘 + 텍스트 병행(PRD §12 접근성).
7. **추천 후보는 카드로 보여주세요.** 노출 판정(2.1 impression)이 카드 단위라서, 폴리곤 색칠이나 목록 텍스트만으로는 "사용자가 봤다"를 기록할 수 없습니다. 자동 회전 캐러셀·한 화면 20장 그리드는 가짜 노출을 만듭니다.
8. **없는 데이터가 기본입니다** — 특산물 226곳 없음 · 공식 코스 236곳 없음 · 운영시간 99.5% 없음 · 착한가격업소 좌표 100% 없음. 섹션이 사라지거나 대체 경로로 넘어가는 것이 예외가 아니라 기본 동작입니다.
9. **디자인 토큰 이름은 유지**하세요. 값은 자유롭게 → [DESIGN-TOKENS.md](DESIGN-TOKENS.md)
